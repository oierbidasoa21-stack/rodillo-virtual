## Pasos que el usuario tiene pendientes: probar la PWA en Chrome para Windows

**A. Instalar**

1. Abrir https://oierbidasoa21-stack.github.io/rodillo-virtual/ (recargar con Ctrl + F5 si estaba abierta de antes).
2. Icono de instalar a la derecha de la barra de direcciones, o menú ⋮ → **Transmitir, guardar y compartir → Instalar página como aplicación…**
3. En la ventana de la app: Ajustes → **Importar athlete.json** con tu `config/athlete.local.json`.
4. Ajustes → **Datos en este dispositivo**: ver si Chrome concedió el almacenamiento persistente.

**B. Sin conexión**

1. Cerrar la app, activar el modo avión (Win + A) y abrirla desde el menú Inicio.
2. Crear una sesión corta (bloques de 0′ 40″ y 0′ 30″), hacerla entera y comprobar que aparece en Historial.
3. Alternativa: Ctrl + Mayús + I → Application → Service workers → **Offline** y Ctrl + R.

**C. Aviso de actualización** (necesita un despliegue nuevo)

1. Con la app abierta, minimizar y restaurar, o Application → Service workers → **Update** (con «Update on reload» desmarcado).
2. Debe salir «Nueva versión disponible». Con una sesión o el editor abiertos se oculta; «Más tarde» lo oculta hasta recargar; «Actualizar» recarga la versión nueva.
